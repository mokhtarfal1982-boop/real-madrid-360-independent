# Real Madrid 360 (ريال مدريد 360)

منصة عربية لمتابعة ريال مدريد: المباراة القادمة، آخر نتيجة، جدولا الدوري ودوري الأبطال، الغيابات، والأخبار.
المنصة موقع ثابت (HTML وCSS وJavaScript دون إطار عمل) يُبنى بسكربت صغير، ويقرأ بياناته الحية من مشروع بيانات منفصل على Vercel.

> هذه نسخة من الكود المصدري القابل للتعديل كما هو في 17 أكتوبر 2026. لا تحتوي أي كلمات مرور أو رموز أو مفاتيح سرية، فالمشروع لا يستخدم أيًا منها.

---

## 1. محتويات المشروع

| المجلد أو الملف | ما فيه |
|---|---|
| `src/index.html` | قالب الصفحة. يضع سكربت البناء روابط الملفات مكان `<!--ASSETS-->` |
| `src/icons.svg` | أيقونات الواجهة |
| `src/js/` | كود الواجهة مقسمًا إلى وحدات تُحمَّل بترتيب أسمائها: أسماء الفرق، الواجهات، المباراة القادمة، آخر نتيجة، الأخبار، الجداول، المباريات، الفريق، تحميل البيانات الحية، التشغيل |
| `site/app.css` | ملف التنسيق كاملًا |
| `site/vercel.json` | إعداد النشر: ربط `/feed/` بمشروع البيانات، وترويسات الأمان (CSP وغيرها) |
| `site/*.png`, `site/icon.svg`, `site/manifest.webmanifest`, `site/robots.txt` | الأيقونات وصورة المشاركة وملف تطبيق الويب |
| `build/compile_data.py` | البيانات المضمّنة في الموقع (المباريات والجداول والغيابات والأخبار الاحتياطية) مع تدقيق الجدول آليًا. يكتب `dist/data-1.js` إلى `data-3.js` |
| `build/build.js` | يصغّر الكود ويقسمه إلى ملفات صغيرة ويكتب الموقع الجاهز في `dist/` |
| `build/make_images.py` | يولّد الأيقونات وصورة المشاركة (اختياري؛ الصور الجاهزة موجودة في `site/`) |
| `build/make_news.py` | يكتب `news/news.json` من الأخبار الاحتياطية |
| `build/make_feed.py` | يولّد ملفات مشروع البيانات الأولية في `feed/work/` |
| `build/feedtool.py` | أداة بناء وتحقق لملفات مشروع البيانات (المباريات، الجداول، الأخبار، الغيابات) قبل نشرها |
| `feed/static/` | الملفان الثابتان لمشروع البيانات (`index.html` و`vercel.json`) |
| `feed/work/` | آخر نسخة من ملفات البيانات الحية: الأخبار `items/`، الغيابات `absences/`، ملاحظات المباراة `notes/`، `matches.json`، `tables.json`، `index.json` |
| `news/` | مشروع الأخبار القديم (احتياطي يقرؤه الموقع إن تعذر مشروع البيانات الجديد) |
| `package.json` | أوامر البناء والحزم المطلوبة |
| `requirements.txt` | حزمة بايثون المطلوبة لتوليد الصور فقط |

لا يوجد خادم خلفي (Backend) ولا قاعدة بيانات: كل البيانات ملفات JSON ثابتة.

## 2. المتطلبات

- Node.js الإصدار 18 أو أحدث: https://nodejs.org (اختر LTS واضغط Next حتى النهاية).
- Python 3.9 أو أحدث: https://www.python.org (في ويندوز فعّل خيار Add Python to PATH أثناء التثبيت).
- اختياري لتوليد الصور فقط: `pip install -r requirements.txt` مع خطوط IBM Plex Sans Arabic وBarlow Condensed.

## 3. التشغيل على جهازك

1. فك ضغط الملف، ثم افتح نافذة الأوامر (Terminal في ماك، أو PowerShell في ويندوز) داخل مجلد `real-madrid-360`.
2. ثبّت حزم البناء مرة واحدة:
   ```
   npm install
   ```
3. ابنِ الموقع:
   ```
   npm run build
   ```
   يكتب هذا الأمر الموقع الجاهز في مجلد `dist/`. (في ويندوز إن لم يعمل `python3` فاستبدله بـ `python` داخل `package.json`.)
4. شغّل معاينة محلية:
   ```
   npm run preview
   ```
5. افتح المتصفح على `http://localhost:3000`.

ملاحظة: في المعاينة المحلية لا يعمل الرابط المختصر `/feed/`، فيقرأ الموقع البيانات الحية مباشرة من `https://real-madrid-360-news.vercel.app/`، وإن تعذر ذلك يعرض البيانات المضمّنة فيه.

## 5. نشر نسخة مستقلة على Vercel

المنصة مشروعان على Vercel:

| المشروع | المحتوى | المجلد الذي يُنشر |
|---|---|---|
| الموقع | الواجهة | `dist/` بعد البناء |
| البيانات | الأخبار والمباريات والجداول والغيابات | `feed/static/` مع محتويات `feed/work/` |

### أ. نشر الموقع
1. أنشئ حسابًا مجانيًا على https://vercel.com.
2. في نافذة الأوامر داخل مجلد المشروع:
   ```
   npm run build
   npx vercel login
   npx vercel deploy dist --prod
   ```
3. أجب عن الأسئلة: اختر حسابك، واكتب اسمًا جديدًا للمشروع (مثل `my-rm360`)، واقبل بقية الخيارات الافتراضية.
4. يظهر في النهاية رابط موقعك.

### ب. نشر مشروع البيانات (اختياري)
إن أردت مصدر بيانات خاصًا بك بدل مصدر البيانات الحالي:
```
mkdir feed-deploy
cp -r feed/static/* feed-deploy/
cp -r feed/work/* feed-deploy/
npx vercel deploy feed-deploy --prod
```
(في ويندوز انسخ محتويات المجلدين يدويًا إلى مجلد `feed-deploy`.)

ثم استبدل العنوان `real-madrid-360-news.vercel.app` بعنوان مشروع بياناتك في ثلاثة مواضع، وأعد البناء والنشر:
1. `site/vercel.json` في قاعدة `rewrites`.
2. `site/vercel.json` في `connect-src` ضمن ترويسة `Content-Security-Policy`.
3. `src/js/07b-feed.js` في القائمة `BASES`.

### تحديث البيانات يدويًا
عدّل ملفات `feed/work/` أو أضف إليها، ثم تحقق منها قبل النشر:
```
python3 build/feedtool.py
```
يعرض الأمر طريقة استخدام أوامر الأداة (`matches`، `tables`، `plan`...). أمر `plan` يتحقق من كل ملف ويكتب `index.json`. بعده أعد نشر مشروع البيانات كما في الخطوة ب.
